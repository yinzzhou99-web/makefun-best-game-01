VOIDPULSE — a neon twin-stick arena survival game in pure canvas 2D with zero libraries: WASD to fly, mouse to aim, hold to fire, Shift to dash through danger. Four enemy types with distinct steering (dart, weaver, stinger, bruiser), escalating waves, a combo multiplier up to ×5, core drops that repair, hasten fire or shield you, particles and screen shake, and a fully synthesised WebAudio soundtrack. It plays offline from its own files.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
# then open out/game/index.html in a desktop browser
```
